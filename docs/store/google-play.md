# Google Play 출시 준비

앱 ID: `com.alasfit.app` · 개인정보처리방침: https://dydwn1003.github.io/workout/privacy.html · 계정 삭제 안내: https://dydwn1003.github.io/workout/delete-account.html

## 1. 업로드 파일(AAB) 만들기

1. 저장소 Settings → Secrets and variables → Actions에 업로드 키 시크릿 4개를 넣습니다: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
2. Actions → **Build Play Store bundle** → Run workflow를 실행합니다. `v1.0.0` 같은 태그를 push해도 됩니다.
3. 약 6분 뒤 https://github.com/dydwn1003/workout/releases/download/android-store/alasfit.aab 에서 파일을 받습니다.
4. 다음 출시 때는 `pubspec.yaml`의 `version: 1.0.0+1`에서 앞부분(1.0.1 등)만 올립니다. 버전 코드는 커밋 수로 자동으로 올라갑니다.
5. 같은 커밋으로 다시 빌드하면 버전 코드도 같아서 Play가 받지 않습니다("이미 사용된 버전 코드"). 새 커밋이 하나라도 있어야 번호가 올라갑니다.

## 5. 테스트와 출시

새로 만든 개인 개발자 계정은 프로덕션 출시 전에 **비공개 테스트**를 거쳐야 해요.

1. 테스트 → 비공개 테스트 → 트랙을 만들고, AAB를 올리고, 테스터 이메일 목록(구글 그룹이나 이메일)을 추가합니다.
2. **테스터 12명 이상이 14일 연속으로 참여**해야 합니다. 테스터는 참여 링크에서 동의한 뒤 Play 스토어에서 설치합니다.
3. 14일이 지나면 대시보드에서 프로덕션 액세스를 신청합니다. 테스트에서 받은 피드백과 반영 내용을 묻는 질문에 답해야 해요.
4. 승인되면 프로덕션 트랙에 출시합니다. 심사에는 보통 며칠 걸려요.

첫 업로드 때 **Play 앱 서명**을 사용하도록 두세요(기본값). 출시 후 Play Console → 설정 → 앱 서명에 나오는 **앱 서명 키 SHA-1**을 Google Cloud의 Android OAuth 클라이언트에 추가해야 Play에서 받은 앱의 구글 로그인이 동작해요.

## 6. 1.1 업데이트(헬스장 커뮤니티)를 올릴 때 바꿀 답변

커뮤니티는 `COMMUNITY=true`로 빌드할 때만 켜져요. Play용 `play.yml`에도 이 값을 추가해야 해요. 올리기 전에 다음 항목을 바꿔 주세요.

- **데이터 보안**: 추가로 체크할 항목
  - 사진 및 동영상 › 사진(수집, 선택, 앱 기능)
  - 앱 활동 › 기타 사용자 제작 콘텐츠(글·댓글: 앱 기능)
  - 개인 정보 › 기타 정보(커뮤니티 닉네임: 앱 기능)
- **콘텐츠 등급**: "사용자가 서로 소통하거나 콘텐츠를 공유할 수 있나요?" → **예**. 사용자 제작 콘텐츠 신고·차단 기능이 있다고 답해요.
- **앱 콘텐츠 → 사용자 제작 콘텐츠(UGC)**: 이용약관(커뮤니티 규칙) 동의, 신고, 차단, 부적절한 콘텐츠 필터가 있다고 답해요.
- 스토어 설명에 "헬스장별 커뮤니티" 소개를 추가해요.
