알아서핏 개인정보처리방침

시행일: 2026년 9월 29일

이용주(이하 "운영자")는 알아서핏 앱(이하 "앱")을 이용하는 분의 개인정보를 「개인정보 보호법」에 따라 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

1. 처리하는 개인정보와 목적

구분항목목적
회원 정보
(로그인 시)		카카오·구글(추후 애플) 계정 식별자, 이메일, 닉네임, 프로필 사진 주소회원 식별, 로그인, 기기 간 기록 동기화, 문의 응대
건강 정보
(민감정보, 이용자가 입력한 경우)		성별, 출생연도, 키, 체중, 체지방률·골격근량, 목표, 식사 기록(음식·칼로리·영양소), 운동 기록칼로리·영양 목표 계산과 주간 조정, 기록 보관과 동기화
이용 기록
(자동 수집, 끌 수 있음)		앱에서 무작위로 만든 기기 식별자, 기능 사용 기록(화면 이동, 기록 방법, 온보딩 단계 등), 결과가 없던 음식 검색어, 기기 종류(웹·안드로이드·iOS), 앱 버전서비스 개선과 오류 분석, 부족한 음식 데이터 보강

이용 기록에는 체중, 칼로리, 먹은 음식 같은 건강 정보가 포함되지 않습니다. 이용 기록은 앱의 설정 → 데이터 → 사용 데이터 보내기에서 언제든 끌 수 있습니다.

로그인하지 않으면 건강 정보는 이용자의 기기에만 저장되고 운영자에게 전송되지 않습니다. 로그인하면 기기 간 동기화를 위해 서버에 저장됩니다.

2. 민감정보(건강 정보)의 처리

운영자는 건강 정보를 이용자의 별도 동의를 받아 처리합니다. 앱 첫 화면에서 건강 정보 저장에 동의해야 이용할 수 있고, 로그인하면 동기화를 위해 서버에 저장됨을 안내합니다. 건강 정보는 본인 계정으로만 접근할 수 있도록 제한되며, 이용자 본인 외에는 조회할 수 없습니다.

3. 보유 및 이용 기간

  • 회원 정보와 동기화된 건강 정보: 회원 탈퇴(계정 삭제) 시 즉시 파기
  • 이용 기록: 수집일로부터 180일 후 자동 파기
  • 로그인하지 않고 기기에만 저장된 정보: 앱의 "모든 데이터 삭제" 또는 앱 삭제 시 기기에서 삭제

4. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 따라 요구되는 경우는 예외로 합니다.

5. 처리 위탁 및 국외 이전

받는 자위탁 업무이전 국가·방법보유 기간
Supabase, Inc.회원 인증, 데이터베이스 저장(동기화된 기록, 이용 기록)대한민국(서울, AWS ap-northeast-2 리전), 이용 시 네트워크로 전송위 3항의 보유 기간과 같음

6. 개인정보의 파기 절차와 방법

보유 기간이 끝나거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다. 전자적 파일은 복구할 수 없는 방법으로 삭제합니다. 계정 삭제 시 계정과 동기화된 모든 기록이 즉시 삭제됩니다.

7. 이용자의 권리와 행사 방법

  • 앱에서 직접 기록을 열람·수정·삭제할 수 있습니다.
  • 설정 → 계정 → 계정 삭제로 계정과 모든 기록을 즉시 삭제할 수 있습니다.
  • 설정 → 데이터 → 사용 데이터 보내기를 끄면 이용 기록 수집이 중단됩니다.
  • 그 밖의 열람·정정·삭제·처리정지 요구는 아래 연락처로 요청할 수 있으며, 지체 없이 조치합니다.

8. 안전성 확보 조치

  • 전송 구간 암호화(HTTPS)
  • 데이터베이스 행 단위 접근 제어: 각 이용자는 본인 기록에만 접근 가능
  • 이용 기록은 서버에 쓰기만 가능하고 앱에서 조회할 수 없도록 제한
  • 관리자 권한 키의 제한적 사용
