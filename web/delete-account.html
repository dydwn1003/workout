알아서핏 계정 삭제

운영자: 이용주 · 앱: 알아서핏

알아서핏 계정과 계정에 저장된 기록은 언제든 직접 삭제하거나 삭제를 요청할 수 있습니다.

1. 앱에서 바로 삭제하기

  1. 알아서핏 앱을 열고 아래쪽의 설정 탭으로 이동합니다.
  2. 계정에서 계정 삭제를 누릅니다.
  3. 확인 창에서 삭제를 누르면 계정과 모든 기록이 바로 삭제됩니다.

로그인하지 않고 쓰는 경우 기록은 기기에만 저장됩니다. 설정 → 데이터 → 모든 데이터 삭제로 지우거나 앱을 삭제하면 모두 사라집니다.

2. 앱을 쓸 수 없을 때 요청하기

앱을 삭제했거나 로그인할 수 없다면, 가입할 때 쓴 계정(카카오·구글·애플)의 이메일로 아래 주소에 삭제를 요청해 주세요. 본인 확인 후 지체 없이(늦어도 7일 안에) 삭제하고 결과를 알려드립니다.

3. 삭제되는 정보

  • 계정 정보: 로그인 계정 식별자, 이메일, 닉네임
  • 건강 정보: 프로필(성별·출생연도·키·목표), 체중·체성분, 식사, 운동, 목표 칼로리 기록
  • 직접 만든 음식과 저장한 식사
  • 헬스장 커뮤니티: 닉네임, 프로필 사진, 작성한 글·댓글·사진, 좋아요, 내 헬스장 목록, 차단 목록

삭제한 정보는 되돌릴 수 없습니다. 기기 식별자만 담긴 익명 이용 기록(건강 정보 없음)은 계정과 연결되지 않으며 수집일로부터 180일 뒤 자동 삭제됩니다. 법령에 따라 보관해야 하는 정보는 없습니다.
